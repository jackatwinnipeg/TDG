# IBM Plex Sans

The website's typeface (mockups/web-v1, owner approved the download 2026-10-29). Used by `css/web.css` only, so
the website loads it and the Android app does not: `build_release.py` leaves this folder out of `release-app/`.
Regular (400), Medium (500) and SemiBold (600), Latin and Latin Extended; other characters fall back to the system font.

- Source: npm `@fontsource/ibm-plex-sans@5.3.0` (Fontsource packaging of IBM Plex), downloaded 2026-10-29, files unchanged
