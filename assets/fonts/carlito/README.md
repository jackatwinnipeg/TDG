# Carlito

Used by `reload_log.html` (the Reload Log sheet): Carlito has the same character widths as
Calibri, the font of the paper form, and is bundled so the sheet looks the same on phones
without Calibri and without a connection (RELOAD_LOG_PROPOSAL.md 3.1).

- Source: Google Fonts, https://github.com/google/fonts/tree/main/ofl/carlito (downloaded 2026-10-25, files unchanged)
- License: SIL Open Font License 1.1, see `OFL.txt`
